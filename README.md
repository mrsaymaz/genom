# Genom (working title): an English RTS by Mr. Saymaz

A touch-first, browser-based real-time strategy game for Grades 5–8 English students (CEFR A1–A2+), part of Mr. Saymaz's English League alongside SnowPax, solMaxima, Languini and Wordramp.

Students lead their own League team (Hufflepuff, Ravenclaw, Gryffindor or Slytherin) through four ages (**Dark, Mythic, Arcane and Celestial**) across three arenas. Every timer in the game (construction, upgrades, training, research and the age-up) can be waited out or finished instantly with English, at 3D task stations built on the SnowPax language bank.

**Status:** first playable slice, played upright (portrait only: on tablets and computers it plays in an upright column). It is for home practice: the tutorial points at what to tap next and gives hints when a student is stuck. Each nation has its own Dark Age units, including an element special (scout, healer, charger or guardian). Matches save themselves (Continue on the start screen), units speak short English lines, and graphics quality adjusts itself to the device. This is a Dark Age tutorial skirmish against one computer rival on an invented map, Sunmeadow Vale. It has no language tasks yet. The game deploys to Vercel as a static browser game, as SnowPax does.

## Play and build

Requires Node 20 or newer.

```bash
npm install
```

```bash
npm run serve
```

`npm run serve` builds the game and serves it at http://localhost:5173.

```bash
npm run build
```

`npm run build` writes the static site to `dist/`. Vercel runs this itself; the settings are in `vercel.json`.

```bash
npm test
```

`npm test` runs the headless simulation tests (map, gathering, building, training, combat, rival pacing).

### Controls

- **Tap** a building to select it. Its actions pop up in a ring around it: train units, set the rally point, or cancel construction. Tap a train button to queue one; **hold** it to queue five. Tap the building again to close the ring.
- **Double-tap** (or long-press) a building to select every building of that type; training then goes to whichever has the shortest queue.
- **Long-press** a worker to open the build wheel straight away. Long-press any other unit to select all of that kind on screen. Long-press the idle-worker button to select every idle worker.
- With soldiers selected, the thumb zone offers **Attack** (attack-move: tap a spot and they fight everything on the way), **Hold** (stay put and strike anything in reach) and **Stop**.
- **Tap** a unit to select it. With workers selected, **Build** (bottom right) opens a wheel of buildings around the worker.
- **Tap** the ground, a tree, berries, a mine or an enemy to give the selected units an order.
- **Drag** to select a group.
- **Two fingers** move the map; **pinch** to zoom.
- **Mouse:** right-click gives orders, right- or middle-drag pans, and the wheel zooms. WASD or the arrow keys also pan.
- Space pauses and Esc cancels.
- **The Town bell:** tap the Town Center, then **Bell**. Workers hide inside and the Town Center shoots harder. Tap **All clear** to send them back to work. A warning appears as soon as a rival army sets off.
- **To place a building:** drag its outline, then tap the tick beside it (or tap the outline again). The cross cancels.
