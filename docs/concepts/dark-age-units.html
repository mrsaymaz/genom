At game size

All sixteen units at the size a student sees them on a phone held sideways (about 20 screen points tall). Each nation should be easy to tell apart by colour and shape, and each unit by its outline: the hat, the shield, the bow, the kite, the boar, the stone.

Age ladder

  • Counters: infantry beats fast units; ranged units beat infantry and guardians; scouts and chargers beat ranged units; guardians beat infantry and fast units; healers keep others alive. The element cycle (Fire beats Earth beats Air beats Water beats Fire) adds a small extra edge.
  • Stats are example values for tuning, with each nation's unit twist already applied. Costs and stats grow with each age (see the roster document).
  • Each unit is drawn as one merged mesh plus one glow mesh, so a full army costs two draw calls per unit type on a phone.
